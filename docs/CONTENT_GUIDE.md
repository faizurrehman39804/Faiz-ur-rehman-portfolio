# Content Guide

## Project Data Rules
Every project must be documented in `src/data/projects.js` with structured information:
- name
- category
- description
- problem
- solution
- features
- technologies
- contribution (Be clear on actual contribution for team projects)
- engineering concepts
- live URL
- GitHub URL
- image/screenshots

Use `TODO:` or `PLACEHOLDER:` when information is missing. Never invent details.
