# Accessibility (a11y) Guidelines

## Standards
- Follow WCAG guidelines where applicable.
- Ensure all interactive elements (buttons, links) are keyboard-focusable and have visible focus states.
- Provide descriptive `alt` text for all meaningful images. Leave `alt=""` for decorative images.
- Ensure sufficient color contrast between text and background elements based on the neutral/dark design system.
- Use native HTML semantic elements instead of `div` + ARIA roles whenever possible.
