# Development Workflow

## Module-Based Development
Every piece of work must be handled MODULE-WISE.

**Workflow Cycle:**
1. Objective definition
2. Current State assessment
3. Required Changes planning
4. Implementation
5. Quality Review (Accessibility, Performance, SEO)
6. Documentation Update
7. Git Commit

## Git Conventions
Use professional, descriptive commit messages.

**Allowed Prefixes:**
- `feat:` New feature
- `fix:` Bug fix
- `refactor:` Code restructuring without behavior change
- `docs:` Documentation updates
- `build:` Build system or structural changes
- `chore:` Maintenance tasks
