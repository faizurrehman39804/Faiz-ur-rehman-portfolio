# Design System

## Visual Direction
- **Style:** Modern, minimal, premium, engineering-focused.
- **Theme:** Neutral/dark visual direction.
- **Typography:** Strong, clean typography using `Inter` for general text and a monospace font for technical details.
- **Spacing:** Clean, consistent spacing using a 4px/8px modular scale.

## CSS Architecture
- Global variables defined in `src/index.css`.
- Colors categorized by function (`bg-primary`, `text-primary`, `accent-primary`).
- Avoid excessive gradients, glassmorphism, or unnecessary 3D elements.

## Animations
- Subtle micro-animations for interactive elements (hover states, focus states).
- No excessive or distracting animations. Performance is prioritized over visual flair.
