# SEO Guidelines

## Technical SEO in React
- As a CSR (Client-Side Rendered) app, we must ensure that essential metadata is present in `index.html`.
- Use a `<title>` and `<meta name="description">` that accurately reflects the primary identity: "Faiz Ur Rehman — Full-Stack Developer".
- Implement Open Graph and Twitter Cards metadata for rich social sharing.
- Ensure semantic HTML tags (`<header>`, `<main>`, `<section>`, `<article>`, `<footer>`) are used to give structure to the content for crawlers that execute JavaScript.
- Avoid keyword stuffing. Maintain professional, natural language.
